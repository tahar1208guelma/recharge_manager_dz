========================================================================
       RECHARGE MANAGER DZ - حزمة تشغيل وبناء نسخة iOS (iPhone/iPad)
========================================================================

هذا المجلد يحتوي على ملفات مشروع Recharge Manager DZ المهيأة بالكامل
للعمل على أجهزة iPhone و iPad ونظام iOS.

1. كيفية تشغيل التطبيق على محاكي iOS أو هاتف iPhone حقيقي:
------------------------------------------------------------------------
- افتح المشروع مباشرة في برنامج Xcode بكتابة الأمر:
  open ios/Runner.xcodeproj

- أو افتح برنامج Xcode واختر:
  File -> Open -> مجلد ios/Runner.xcodeproj

- اختر الجهاز (iPhone 15/16 Simulator أو هاتفك المتصل).
- اضغط على زر التشغيل (▶️ Run).

2. بناء ملف IPA لتثبيته على الأجهزة (Distribution):
------------------------------------------------------------------------
من داخل برنامج Xcode:
1. اختر القائمة العلوية: Product -> Archive
2. بعد اكتمال الـ Archive، اضغط على زر Distribute App
3. اختر طريقة التوزيع المناسبة (Development / Ad Hoc / TestFlight / App Store)
4. سيتم إنتاج ملف .ipa الجاهز للتثبيت عبر Apple Configurator أو AltStore أو TestFlight.
