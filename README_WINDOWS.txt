========================================================================
       RECHARGE MANAGER DZ - حزمة تثبيت وتشغيل نسخة الويندوز
========================================================================

هذا المجلد يحتوي على ملفات برنامج Recharge Manager DZ الجاهزة للتشغيل
والبناء على نظام Windows Desktop.

1. كيفية تشغيل أو بناء ملف التنصيب على Windows:
------------------------------------------------------------------------
- لإنشاء ملف التشغيل المستقل (recharge_manager_dz.exe):
  قم بالضغط مرتين (Double Click) على الملف:
  build_windows.bat

- أو اكتب في موجه الأوامر (CMD):
  flutter build windows --release

2. مكان وجود البرنامج بعد البناء:
------------------------------------------------------------------------
تجد الملف التنفيذي وكافة ملحقاته في المجلد:
build\windows\x64\runner\Release\recharge_manager_dz.exe

3. لإنشاء ملف Setup.exe لتثبيت البرنامج لدى الزبائن:
------------------------------------------------------------------------
افتح برنامج Inno Setup المجاني واختر الملف:
windows\installer\recharge_manager_dz_setup.iss
ثم اضغط Compile لإنشاء: RechargeManagerDZ_v1.0_Windows_Setup.exe

4. بيانات تسجيل الدخول الافتراضية:
------------------------------------------------------------------------
اسم المستخدم: admin
كلمة المرور: admin123
========================================================================
